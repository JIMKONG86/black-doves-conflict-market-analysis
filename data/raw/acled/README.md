# ACLED source-data notice

The original ACLED weekly export used during development is not redistributed
through this public repository. Derived weekly aggregates and the analytical
features used by the submitted study are available under `data/validated/` and
`data/analysis/`.

The optional acquisition and preparation implementation is documented in
`acled_API/` and the related project README files. A new download requires the
user's own authorised ACLED access and may not reproduce the frozen submission
if the provider's database has changed.
